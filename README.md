# 🎬 Movie Recommender

A website that shows trending movies, lets you search, filter by genre,
save a watchlist, and get recommendations based on a movie you like.

## Features
- Trending movies
- Search
- Genre filter
- Watchlist (saved in your browser)
- Similar movie recommendations

## Tech used
HTML, CSS, JavaScript, TMDB API

## How to run
1. Clone the repo
2. Copy `config.example.js` to `config.js` and add your TMDB API key
3. Open `index.html` with Live Server
